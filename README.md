Prompt to Paid ($PROMPT) — the coin of the AI agent that turns one prompt into a shipped program and a paid bounty on make.fun. Launched on pump.fun for the make.fun coin bounty; the coin itself is the entry, and `LAUNCH.json` names its mint and create-transaction signature.

## Run it

```sh
mkdir -p out && MAKEFUN_BOT_DIR=. MAKEFUN_OUTPUT_DIR=out node main.ts
```
